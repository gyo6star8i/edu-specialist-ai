내 요청문 만들기

칸을 채우면 아래에 요청문이 만들어집니다. 쓴 내용은 이 노트북 브라우저에만 저장되고, 실습 2에서 그대로 불러옵니다.

경북교육청 장학사의 업무 도구를 만들어줘.
학교별 제출 자료를 붙여넣으면 집계하는 웹페이지야.
- 대상: 【나와 담당 학교 교무부장】
- 입력: 【학교명·학생 수·참여 인원 표 붙여넣기】
- 출력: 【학교별 합계표와 미제출 학교 목록】
- 규칙: 【명단에 있는데 자료가 없으면 ‘미제출’】
예시 데이터 5줄을 넣어 바로 시험할 수 있게 해줘.

  
경북교육청 장학사의 업무 도구를 만들어줘.
공모사업 심사위원 점수를 넣으면 평균과 순위를 내는 웹페이지야.
- 대상: 【나와 심사위원 5명】
- 입력: 【학교명과 심사위원별 점수(100점 만점) 표 붙여넣기】
- 출력: 【학교별 평균 점수와 순위표, 동점 학교 표시】
- 규칙: 【위원별 최고점과 최저점을 하나씩 빼고 평균】
예시 데이터 5줄을 넣어 바로 시험할 수 있게 해줘.

  
경북교육청 장학사의 업무 도구를 만들어줘.
행사 날짜를 넣으면 준비 일정을 거꾸로 계산하는 웹페이지야.
- 대상: 【나와 행사 담당 주무관】
- 입력: 【행사 날짜와 준비 항목별 ‘며칠 전까지’】
- 출력: 【항목별 마감 날짜와 오늘 기준 남은 날 수】
- 규칙: 【마감일이 주말이면 바로 앞 금요일로 당기기】
예시 데이터 5줄을 넣어 바로 시험할 수 있게 해줘.

【실습 1에서 쓴 요청문 붙여넣기】

조건: HTML·CSS·JavaScript를 한 파일에 담고, 서버나 로그인 없이 브라우저에서만 동작하게 해줘.
입력한 데이터는 어디에도 저장하거나 전송하지 마. 화면은 한글로, 맨 위에 사용법 안내를 넣어줘.
예시 데이터를 넣어 바로 시험할 수 있게 하고, 완성된 코드 전체를 한 번에 보여줘.

  
이어서 요청하기 (같은 채팅에)

  

    
    
    
    
  

  
오류는 “무엇을 넣었더니 무엇이 나왔다”처럼 보이는 그대로 말하는 것이 가장 빠릅니다.

  

    완성한 코드를 index.html 파일로 저장하기
    

      
Claude — 결과 화면 오른쪽 위의 다운로드(또는 복사) 버튼으로 받습니다. 받은 파일 이름을 index.html로 바꿉니다.

      
Gemini · ChatGPT — Canvas의 코드 보기에서 전체를 복사한 뒤, 아래 방법으로 파일을 만듭니다.

      
Windows — 메모장에 붙여넣기 → 다른 이름으로 저장 → 파일 형식 모든 파일, 인코딩 UTF-8, 이름 index.html

      
Mac — 텍스트 편집기에서 포맷 → 일반 텍스트로 만들기 후 붙여넣기 → 이름 index.html로 저장 (‘.txt 추가’ 해제)

      
저장한 파일을 더블클릭해서 브라우저에서 열리면 성공입니다.

    

  

  
만든 도구, 이것만은 확인

    
  • 계산 규칙 — 지침의 기준과 계산 결과가 맞나요?
  • 끝자리 값 — 기준일 당일·빈칸·0 같은 경계의 값도 넣어 봤나요?
  • 데이터 흐름 — 입력한 자료가 화면 밖으로 나가지 않나요?

  

  
도구의 결과는 판정이 아니라 참고입니다. 최종 판단은 지침과 담당자가 합니다.
